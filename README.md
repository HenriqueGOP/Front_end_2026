# Front-end — atividades 2026

Repositório de exercícios e trabalhos acadêmicos utilizando **HTML, CSS e JavaScript**. As pastas representam diferentes momentos de aprendizado, não uma única aplicação integrada.

## Índice de atividades

- [HTML](HTML/) — páginas e scripts introdutórios.
- [Trabalho CSS](Trabalho%20CSS/) — atividades com CSS, Bootstrap e DaisyUI.
- [Trabalho adicionar na lista](Trabalho%20adicionar%20na%20lista/) — interações de lista em JavaScript.
- [Semana 9 — Trabalho](Semana%209_Trabalho/) — exercícios de aula.
- [Trabalho — Prova da Copa](Trabalho_Prova%20da%20copa/) — HTML, CSS e JS.
- [Busca binária](Busca%20binaria%202702/) — atividade de busca.
- [Trabalho](Trabalho/) — páginas de prática.

## Executar

Abra o arquivo `index.html` da pasta correspondente no navegador. Para funcionalidades dependentes de servidor, utilize uma extensão como Live Server no VS Code.

## Sobre o histórico

Todos os arquivos de código originais foram preservados para registrar o processo de aprendizagem.
